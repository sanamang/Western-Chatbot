# About Western Directory

The Western Directory help section contains information about the Western Directory and how to use as well as information for directory coordinators on how to update their directory listings

The **Units and Departments** searches allow you to display a unit's organizational structure, provided that such information has been entered into Western Directory. From the unit result page, click on the **Organization** link. More infromation can be found in the Navigating and using the Directory page.
